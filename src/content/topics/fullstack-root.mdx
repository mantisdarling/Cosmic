## What is Full Stack?

A **full stack developer** works on both the frontend (what users see) and the backend (servers, databases, APIs). The "stack" refers to all the layers of technology that make a web application work.

## The layers

```
Browser (User)
    ↕
Frontend: HTML, CSS, JavaScript, React
    ↕  HTTP
Backend: Node.js + Express (REST API)
    ↕
Database: PostgreSQL / MongoDB
    ↕
Infrastructure: Servers, CDNs, CI/CD
```

## Learning path

This roadmap takes you from the very basics to deployment-ready applications. Start at the top and work your way down — each layer builds on the previous.

**Estimated time**: 6–12 months of focused study and building projects.

## The most important advice

**Build things.** Reading tutorials is not enough. After every concept, build a small project that uses it. Your portfolio of projects is what gets you hired, not your ability to recite definitions.
