## What is it?

**HTML** (HyperText Markup Language) provides the structure of web pages — headings, paragraphs, links, images, forms. **CSS** (Cascading Style Sheets) controls the visual presentation: colors, fonts, layouts, animations.

Every browser renders HTML + CSS. No framework, build step, or server required — just open a `.html` file.

## Why it matters

You cannot build anything for the web without HTML & CSS. Even if you end up working primarily in React or another framework, you're still writing HTML and CSS under the hood — understanding the fundamentals means you can debug problems that frameworks abstract away.

## Key concepts to learn

- Document structure (`<!DOCTYPE>`, `<head>`, `<body>`)
- Common elements: headings, paragraphs, links, images, lists, forms, tables
- Box model: margin, border, padding, content
- CSS selectors and specificity
- Colors, fonts, units (px, %, rem, em, vh/vw)
- Responsive design basics (media queries)
- CSS variables (`--custom-property`)
