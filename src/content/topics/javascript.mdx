## What is it?

JavaScript is the only programming language that runs natively in every web browser. It adds interactivity to web pages (click handlers, form validation, animations), and — via Node.js — also runs on servers.

## Why it matters

JavaScript is unavoidable in web development. React, Vue, Angular, Node.js, TypeScript — they're all JavaScript. Mastering the fundamentals gives you a foundation that transfers to every framework.

## Key concepts to learn

- Variables (`let`, `const`), data types, operators
- Functions (declarations, expressions, arrow functions)
- Arrays and objects — the data structures you'll use constantly
- Control flow: `if/else`, loops, `switch`
- Scope, closures, `this`
- ES6+ features: destructuring, spread/rest, template literals, modules
- Error handling with `try/catch`
