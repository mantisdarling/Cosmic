## What is it?

Git is a distributed version control system that tracks changes in your source code over time. GitHub (and GitLab, Bitbucket) are hosting platforms for Git repositories that add collaboration features like pull requests, code review, and issue tracking.

## Why it matters

Every professional developer uses Git daily. It's the backbone of collaborative software development — without it, working in a team means emailing zip files. Even solo, Git gives you an undo button for your entire project history, and GitHub serves as both a portfolio and a deployment platform.

## Key concepts to learn

- `git init`, `git clone`
- `git add`, `git commit`, `git push`, `git pull`
- Branches: `git branch`, `git checkout`, `git merge`
- Understanding `HEAD`, staging area, and working tree
- Reading `git log` and `git diff`
- Resolving merge conflicts
- `.gitignore` — what to exclude
- Pull Requests and code review workflow
